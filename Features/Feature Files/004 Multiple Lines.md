# Multiple Lines

Modify the solution in index.html to support the concept of multiple pathways.

1. Add a button which allows the user to start a new path from the controls in the corner.
1. A new path should leave the old path intact and allow the user to place new pins and lines without affecting the old path.
1. A new path should be visually distinct from the old path (e.g. different colours for pins and lines)
1. A new path should have its own section in the stats table, with a clear visual separation from the previous path's data.
1. The total distance for each path should be calculated independently.
1. An Overall total of all paths should be displayed seperately
1. The save and load functions should be updated to support multiple paths, ensuring that all paths and their associated data are preserved when saving and loading from a CSV file.
1. The share via URL function should also be updated to encode multiple paths and their data, allowing users to share complex multi-path configurations with others.
