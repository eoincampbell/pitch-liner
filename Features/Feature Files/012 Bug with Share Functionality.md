# Share Functionality

When you "Close a Shape" and then use the "Share" function, the shared url does not include the enclosed area highlight or the label with the path name. 

The Save, Load and Share functions should be updated to include the fact that a path has been "Closed" and when an enclosed shape is reloaded (either by loading or visiting a shared url), the enclosed area highlight and the label with the path name should be displayed.
