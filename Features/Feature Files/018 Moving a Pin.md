# Ability to move a pin

When you click on the map you place a pin
When you click and hold on the map you can drag and move it around.

I'd like the ability to click and hold on any existing pin, in any path (active or not) so that you can drag the position of the pin slightly. this should move that pin accordingly compared to the other pins in the same path.
It should update the lines, update the stats on the left bar, and update the path information in the path info box. If the path is already "closed" ti can "reopen" the path, similar to how adding a new pin to an existing path clears the path overlay
