# Stats Panel Improvements

The Stats Panel in the left side bar is a little bit cramped and could do with some general UX improvements.

1. The "Pin Labels" and "Unit: Dropdowns" are ugly and unaligned.
1. The 8 buttons are all just thrown in there with no spacing grouping or logic to their placement.
1. The status section for each route is fine, and I do like the color indicators and active notice, but they become cramped when you have 5-6 routes with 4 points each.
1. The Help Button launches a "Help" Lightbox, but this information is out of date and needs to be updated/amended to bring it in line with the latest version of the app.
1. The Map can be rotated, zoomed, tilted to other locations and positions, this needs to be reflected in the save/load data and in the share url.
1. There seems to be an issue with searching in "Search for an address" text box. It might be a function of the specific azure maps API that's being used, but it doesn't seem to find certain locations like GAA grounds. Do an analysis of the API used, and settings used to see if it can be improved.
