# Better Pin Labels

Right now Pin Labels can be enabled by a toggle switch.

Change this to a dropdown menu with the following options:
- Off 
- Individual Distance
- Cumulative Distance

The default behavior is "Off" and the user can change it to either of the other two options. 
When "Individual Distance" is selected, each pin will display the distance from the previous pin. 
When "Cumulative Distance" is selected, each pin will display the total distance from the starting point.
