# Suggested Features

1. **Undo Last Pin** – Add an "Undo" button that removes the most recently placed pin, its connecting line, and updates the table and total distance accordingly.

2. **Distance Unit Toggle** – Allow the user to switch between metres, yards, kilometres, and miles, with all displayed distances updating in real time.

3. **Area Calculation** – When three or more pins are placed, offer a "Close Shape" option that connects the last pin back to the first and calculates the enclosed area in square metres.

4. **Pin Labels on Map** – Display the pin number (and optionally the cumulative distance) as a label directly on the map next to each pin marker. Enabling/Disabling this should be a checkbox in the top corner.

5. **Elevation Profile** – Fetch elevation data for each pin from an elevation API and display a mini elevation chart alongside the stats panel.

6. **Share via URL** – Encode the current pin data into a shareable URL (or short link) so that another user can open the same set of pins and m6asurements without needing to exchange CSV files.
