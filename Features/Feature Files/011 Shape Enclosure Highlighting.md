# Shape enclosure highlighting

When a shape is enclosed using the "Close Shape" function, the enclosed area remains non-obvious. 

To enhance visibilty an semi-transparent highlight layer should be added to the enclosed area and the name of the path should be added as a label in the center of the enclosed area.

If the path name is updated using the tools on the side, then the path name on the label in the enclosed area should also be updated to reflect the new name.
