# Pin Labels Upgrade

Once Pin Labels are enabled, the pin names only appear for the first path.

This is a problem because if you have multiple paths, you won't be able to see the pin names for the other paths, which makes it difficult to understand which pins are which.

The solution is to make the pin labels appear for all paths, not just the first one. 

Pin numbers should restart for each path, so that the first pin in each path is labeled "Pin 1", the second pin is labeled "Pin 2", and so on.
