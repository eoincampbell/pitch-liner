# Pin Label Improvements

Pin Labels formatting needs work. when the label is visible above the pin is should only show "pin number" and on the line beneath it should show "Distance from previous Pin" 
Currently it shows total cumulative distance.

E.g.
#1

#2
20m

#3
47m

#4
20m

This means 
Pin 1 (no distance since it's first pin)
Pin 2 - 20 units of distance from pin 1
Pin 3 - 47 units from pin 2
Pint 4 - 20 units from pin 3

Also, Pin labels only seem to work for the first route. They do not appear for additional added paths.
