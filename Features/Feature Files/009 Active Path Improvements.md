# Active Path Improvements

Right now, once you add a new path, that new path becomes "Active" and the previous path is no longer active. This means that if you add a new pin, it will be added to the new path, not the previous one.

However it would be good to be able to switch back to another path, to make modifications, or to add new pins to it.

Modify the UX so that the user can select which path is "Active" from the stats section on the left panel.
